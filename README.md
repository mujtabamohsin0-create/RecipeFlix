# 🍽️ RecipeFlix

A full-featured recipe sharing platform inspired by Netflix's UI design. Browse, save, and manage your favorite recipes with a cinematic experience.

## ✨ Features

- **Netflix-style Interface** - Clean, modern UI with video backgrounds
- **User Authentication** - Secure login and registration system
- **Recipe Management** - Add, edit, and delete recipes (Admin only)
- **My List** - Save your favorite recipes to a personal collection
- **Category Filtering** - Browse recipes by category (Italian, Pakistani, Japanese, etc.)
- **Search Functionality** - Find recipes by title
- **Responsive Design** - Works on desktop, tablet, and mobile devices
- **Lazy Loading** - Optimized image loading for better performance
- **3D Parallax Effects** - Interactive video backgrounds

## 🛠️ Tech Stack

- **Backend**: PHP 7.4+
- **Database**: MySQL
- **Frontend**: HTML5, CSS3, JavaScript
- **Authentication**: PHP Sessions with password hashing
- **Fonts**: Google Fonts (Bebas Neue, Montserrat)

## 📋 Prerequisites

- XAMPP / WAMP / MAMP or any PHP + MySQL environment
- PHP 7.4 or higher
- MySQL 5.7 or higher
